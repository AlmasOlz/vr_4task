Приложение подготовлено на основе [petrenko-alex/ar-nav](https://github.com/petrenko-alex/ar-nav). Автор оригинала: Alexander Petrenko, 2018. Лицензия: GPL-3.0 (`LICENSE`). Оригинальное описание сохранено в `README.upstream.md`.

Приложение: https://almasolz.github.io/vr_4task/

Маркеры: https://almasolz.github.io/vr_4task/markers.html

## Использование

1. Откройте маркер на другом устройстве или распечатайте. В кадре должны быть видны изображение Hiro и QR-код.
2. Выберите цель и нажмите «Исследовать». Разрешите доступ к камере.
3. Сканируйте маркер под прямым углом с расстояния примерно 30–40 см. Синяя 3D-стрелка показывает направление к следующей точке.
4. Если отсканирован маркер вне текущего маршрута, путь рассчитывается заново. Зелёная метка означает достижение цели.
5. Для возврата и изменения цели используйте кнопку «Назад» браузера. Поверх камеры нет постоянных меню и кнопок.

Используется **демонстрационный этаж кафедры ПОАС из оригинального репозитория**, а не карта здания пользователя. Для реальной навигации нужны соответствующий план, направления и расставленные маркеры.

Пример пути к аудитории 903: `m_901_1` (QR 64) → `m_901_2` (65) → `m_902_1` (66) → `m_902_2` (67) → `m_902_3` (68) → `m_903` (69). Дома можно показывать эти изображения по очереди с другого экрана.

## Адаптация

Сохранены Vue/Vuetify, 16 оригинальных маркеров, 13 объектов этажа, направления и 3D-модели. Русские названия, приветствие, инструкции и голосовые команды взяты из оригинала.

Для GitHub Pages граф и поиск кратчайшего пути выполняются в браузере (`src/navigation`); оригинальный PHP/Neo4j-код оставлен в `api/` для справки. Pages не выполняет PHP. Внешняя база и API-ключи не нужны. Аналитика и анкеты не отправляются; кадры камеры и результаты сканирования не передаются на сервер.

QR-декодер и AR используют один видеопоток. Для телефона запрашивается HD-камера, QR обрабатывается с шириной до 1280 пикселей, AR-трекинг — 640 × 480. Геометрия AR-холста сохраняет тот же масштаб и обрезку, что и изображение камеры.

Локальные библиотеки: A-Frame 0.9.2, AR.js 2.0.8, jsQR 1.4.0. Лицензии находятся в `public/vendor`. Цвет и размер оригинальных моделей адаптированы для отображения на маркере.

`public/patt.nav` обучен на внутренней области оригинальной составной метки (Hiro + QR). Обычный `patt.hiro` не учитывает QR-код и хуже распознаёт такую метку при небольшом размере в кадре. Проверены все 16 изображений из оригинального набора. Для работы используйте именно маркеры со страницы «Маркеры».

## Сборка

```text
npm ci --legacy-peer-deps --ignore-scripts
npm run test:navigation
npm run build
```

Поддерживается Node.js 24; совместимость старого Vue CLI с OpenSSL настроена в `scripts/build.cjs`. Готовые файлы публикуются из `docs/`, полный исходный код доступен в том же репозитории. Для локального просмотра запустите `start.cmd` и откройте `http://localhost:8004`.

Проверяются маршруты от всех 16 точек к 12 целям, повторный расчёт и достижение цели. Браузерные проверки используют синтетическую камеру с оригинальными маркерами и реальные алгоритмы jsQR/AR.js. Физический телефон не использовался.
