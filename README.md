# vr_4task — AR-Nav

4-тапсырма [petrenko-alex/ar-nav](https://github.com/petrenko-alex/ar-nav) негізінде орындалды. Автор: Alexander Petrenko, 2018. Лицензия: GPL-3.0 (`LICENSE`). Түпнұсқа сипаттамасы: `README.upstream.md`.

Телефоннан ашу: https://almasolz.github.io/vr_4task/

Маркерлер: https://almasolz.github.io/vr_4task/markers.html

## Қолдану

1. Маркер бетін басқа құрылғыда ашыңыз немесе қағазға басып шығарыңыз. Маркердегі Hiro өрнегі мен QR коды түгел көрінсін.
2. Қолданбада баратын аудиторияны таңдап, «Камераны қосу» түймесін басыңыз. Камераға рұқсат беріңіз.
3. Камераны маркерге тура қаратып, шамамен 30–40 см қашықтықтан көрсетіңіз. Көк 3D жебе келесі нүктенің бағытын көрсетеді.
4. Келесі маркерді сканерлеңіз. Басқа жерге бұрылып кетсеңіз, сол жердегі маркерден маршрут қайта есептеледі. Мақсатта жасыл 3D белгі пайда болады.
5. Камера көрінісінде мәзір, батырма мен мәтін жоқ. Қайту және мақсатты өзгерту үшін браузердің «Артқа» батырмасын басыңыз.

**Бұл автордың үлгі қабатының маршруты, пайдаланушы ғимаратының картасы емес.** Үлгі: 901 → 903; бастапқы маркер `m_901_1` (QR 64), одан кейін `m_901_2` (65), `m_902_1` (66), `m_902_2` (67), `m_902_3` (68), `m_903` (69). Үйде тексеру үшін осы суреттерді кезекпен басқа экранда көрсетуге болады. Нақты ғимаратта қолдану үшін оның өлшенген жоспары, дұрыс бағыттары және орналастырылған маркерлері керек.

## Түпнұсқадан өзгерістер

- Vue/Vuetify қолданбасы, түпнұсқа 16 маркер, үлгі қабаттың 13 объектісі мен бағыттары, жебе және мақсат моделі сақталды.
- PHP/Neo4j серверінің орнына үлгі графтағы ең қысқа маршрут браузерде есептеледі (`src/navigation`). Түпнұсқа PHP коды `api/` ішінде анықтама ретінде сақталған, GitHub Pages оны орындамайды.
- QR сканер мен AR бір камера ағынын пайдаланады; телефонда екі камера сұрауын қатар ашу жойылды.
- Баратын жер камера ашылғанға дейін таңдалады; сауалнама, аналитика мен камера үстіндегі басқару элементтері қолданылмайды. Камера кадрлары, QR нәтижелері мен маршрут серверге жіберілмейді.
- Кітапханалар жергілікті: A-Frame 0.9.2, AR.js 2.0.8, jsQR 1.4.0. Жебе мен мақсат белгісінің өлшемі маркерге сыйдырылып, көк және жасыл түске өзгертілді.

## Іске қосу және тексеру

Дайын жинақты компьютерде ашу: `start.cmd` → `http://localhost:8004`.

Қайта жинау (Node.js 24 және npm):

```text
npm ci --legacy-peer-deps --ignore-scripts
npm run test:navigation
npm run build
```

`docs/` — GitHub Pages жариялайтын дайын жинақ; `src/`, `public/`, `scripts/`, `package-lock.json` — оны қайта жинауға жеткілікті бастапқы код. Ескі Vue CLI үшін OpenSSL үйлесімділігі жинау сценарийінде орнатылған. Орта айнымалысы немесе API кілті қажет емес.

Тексеру: барлық 16 нүктеден 12 мақсатқа жол бар екені, қате сканерден қайта бағыттау және жету күйі тексерілді. Браузерде жасанды камераға түпнұсқа маркер суреттері беріліп, нақты jsQR және AR.js алгоритмдерімен QR/Hiro танылуы, 3D модельдер, бір камера, маркер жоғалғандағы жасырыну және сыртқы API сұрауларының жоқтығы тексерілді. Нақты физикалық телефон камерасымен сынау жүргізілген жоқ.
